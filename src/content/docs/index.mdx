## 主要功能

<CardGrid>
  <Card title="Steam 创意工坊" icon="rocket">
    在应用内浏览、搜索并订阅创意工坊中的模组,无需来回切换窗口。
  </Card>
  <Card title="模组套件" icon="setting">
    把模组按玩法保存成不同的"模组套件",一键切换。也可以从 Better Mod Loader(BML)导入已有配置。
  </Card>
  <Card title="一键启动游戏" icon="right-caret">
    不用再切到别处,直接在 SuperDucky 里启动《逃离鸭科夫》。
  </Card>
  <Card title="统一管理" icon="puzzle">
    本地模组、创意工坊订阅和 NuGet 模组放在同一个列表里,支持分组、拖拽排序、历史还原和健康检查。
  </Card>
  <Card title="NuGet 市场" icon="download">
    启用后可以浏览并安装发布在 NuGet 上的模组,也是存档图鉴所需的 SuperDucky.Connector 的来源。
  </Card>
  <Card title="存档图鉴" icon="open-book">
    读取游戏存档,按分类展示收集到的物品,并支持最多 6 个物品的属性对比。
  </Card>
</CardGrid>
