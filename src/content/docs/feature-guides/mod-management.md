模组管理是 SuperDucky 的核心功能。你可以在这里安装、启用、排序和更新模组,模组来源包括本地文件、Steam 创意工坊和 NuGet 包。

## 界面布局

模组管理页面分为左右两栏:

- **左侧**是模组分组列表。
- **右侧**显示所选分组中的全部模组。

### 模组套件

应用里把"配置文件"叫作**模组套件**。套件让你为不同的游戏场景保存独立的模组组合。打开"模组套件管理"对话框,可以:

- **新建**、**重命名**、**删除**套件。
- **切换到**另一个套件,当前生效的套件会标上"生效中",并显示已启用的模组数量。
- **BML 导入**:导入 Better Mod Loader(BML)的配置。如果 SuperDucky 检测到 BML 的配置,也会自动把它导入为一个套件。

## 浏览模组列表

### 显示模式

| 模式 | 特点 |
| --- | --- |
| 默认 | 显示预览图、名称、来源标签和启用开关 |
| 紧凑 | 缩小卡片间距,一屏显示更多模组 |
| 单行 | 最紧凑,只保留必要信息 |

每张模组卡片包含预览图、名称、来源标签(本地、Steam 创意工坊或 NuGet)和启用开关。

### 筛选与搜索

- **来源**:按本地、Steam 或 NuGet 筛选。
- **状态**:按已启用或已禁用筛选。
- **搜索框**:输入模组名称或 ID,实时过滤。

### 批量操作

筛选之后,可以对当前结果一键**全部启用**或**全部禁用**。

## 分组与加载顺序

### 拖拽分组

1. 在模组卡片上按住鼠标左键。
2. 拖到左侧的目标分组上。
3. 松开鼠标完成分组。

### 调整加载顺序

模组的加载顺序会影响游戏运行,有些模组必须排在其他模组之后才能正常工作。

- 在同一分组内**拖拽**卡片调整位置。
- 或在右键菜单中选择**移到分组开头**或**移到分组末尾**。

### 右键菜单

在模组卡片上点击右键:

| 操作 | 说明 |
| --- | --- |
| 启用 / 禁用 | 切换启用状态 |
| 移动到分组 | 移到指定分组 |
| 移到分组开头 / 末尾 | 调整加载顺序 |
| 打开文件夹 | 在文件管理器中打开模组所在目录 |
| 查看 Steam 详情 | 在创意工坊中查看(仅 Steam 模组) |

## 还原历史记录

调整分组之后想退回去?打开"还原历史记录"对话框,选择一个历史版本。列表会显示每个版本的时间、分组数、模组数和已启用数。选定版本后,**需要点击保存按钮确认**,还原才会生效。

## 模组详情

点击模组卡片打开详情面板。

**本地模组**显示预览图、模组路径、文件夹名称和依赖项,并提供"打开文件夹"按钮;如果它同时是 Steam 模组,还会提供"查看 Steam 详情"。

**Steam 创意工坊模组**还会显示订阅数、评分、最后更新时间、作者链接、描述(支持 BBCode)、预览画廊、依赖树和版本历史,并可直接订阅或取消订阅。

## Steam 创意工坊

SuperDucky 与创意工坊集成,可以直接在应用内浏览并订阅模组。

- **订阅**:在 Steam 模组详情中点击"订阅"。下载由 Steam 自动完成。
- **更新检查**:SuperDucky 会定期检查已订阅模组的更新,有更新时卡片上会出现提示。
- **更新**:更新由 Steam 客户端完成,更新状态可在健康检查中查看。

## 健康检查

SuperDucky 会自动检查模组配置,并在界面右上角显示健康状态条。

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 配置健康,未发现问题 |
| 黄色 | 有警告,例如缺少依赖项 |
| 红色 | 有错误,例如模组冲突 |
| 灰色 | 所有问题都已被忽略 |

点击状态条打开健康报告,可以查看错误、警告和已忽略的问题,查看修复建议,并忽略或取消忽略某个问题。修复后状态会自动更新。

## 常见问题

### 模组无法启用

依次检查:

1. 模组文件是否完整。
2. 是否缺少必需的依赖模组。
3. 是否存在冲突,可在健康报告中查看。
4. 模组是否兼容当前的游戏版本。

### Steam 模组没有显示

1. 确认已在 Steam 中订阅该模组。
2. 等待 Steam 下载完成。
3. 确认 Steam 客户端正在运行。
4. 在 SuperDucky 中刷新模组列表。

### 游戏出现异常,怀疑是加载顺序问题

- 把基础模组放在前面,依赖其他模组的放在后面。
- 在模组详情里查看依赖项。
- 用健康检查找出依赖问题。
